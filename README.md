**Лабораторная работа №1: Табличные агенты для задачи навигации дрона

Содержание папки:

1.  code1.1(старый).ipynb -- первая версия кода

2.  code1.2(новый).ipynb -- финальная версия кода (5 независимых
    > запусков, повторные эксперименты)

3.  8BM52 Фань Синьюэ_ЛБ1.1.pdf -- первый вариант отчёта
    > (предварительные результаты)

4.  8BM52 Фань Синьюэ_ЛБ1.2.pdf -- итоговый отчёт (после повторных
    > экспериментов)

5.  Отчёт об использовании искусственно.docx -- отчёт об использовании
    > ИИ с перечнем исправленных ошибок

6.  выходные изображении -- папка со всеми визуализациями (графики
    > обучения, CDF, тепловые карты, траектории)

Как запустить:

-   Откройте code1.2(новый).ipynb в Jupyter Notebook / VS Code / Google
    > Colab.

-   Последовательно выполните все ячейки (Run All).

-   Обучение трёх агентов (рациональный, Prospect Q‑learning,
    > риск‑чувствительный) займёт несколько минут (15000 эпизодов на
    > агента × 5 запусков).

-   После выполнения вы увидите:

    -   консольные таблицы с метриками (среднее ± стандартное отклонение
        > по 5 запускам);

    -   визуализации будут сохранены в папку выходные изображении.

Примечания:

-   Фиксированный seed для воспроизводимости: SEED = 42, основные
    > запуски используют RUN_SEEDS = \[100, 200, 300, 400, 500\].

-   Все три агента обучаются в одной и той же среде (турбулентный ветер,
    > 4 препятствия, нелинейный расход батареи).

-   Параметры рационального агента: γ=0.99, α=0.10, ε-greedy с
    > затуханием.

-   Prospect Q‑learning: α_p=0.88, β_p=0.88, λ_p=2.35.

-   Риск‑чувствительный агент: η=0.5 (энтропийная полезность).

-   В случае вопросов или ошибок проверьте, установлены ли библиотеки
    > numpy, matplotlib, seaborn, scipy.
